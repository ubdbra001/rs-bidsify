# Installation

`RS-BIDSify` is not currently available on PyPI, so it needs to be installed directly from github.
All cases below assume that you have already created and activated a virtual environment to install the package into.


## Direct installation

### Using `pip`
```sh
pip install git+https://github.com/ubdbra001/rs-bidsify.git
```
### Using `uv`
``` sh
uv add git+https://github.com/ubdbra001/rs-bidsify.git
```

## Clone and install

Download the repository locally
``` sh
git clone https://github.com/ubdbra001/rs-bidsify.git
```

### Using `pip`
``` sh
pip install path/to/rs-bidsify
```

### Using `uv`
``` sh
uv add path/to/rs-bidsify
```
